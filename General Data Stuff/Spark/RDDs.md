The foundational data structure of spark. DataFrames are build on top of them. Useful for processing unstructured data which DataFrames can't be used for.

*a fault-tolerant collection of elements partitioned across the nodes of a cluster that can be operated on in parallel*

**Fault-tolerant/resilient** - data copied across multiple clusters and recoverable in the event of a failure
**Partitioned/distributed** - datasets split up across multiple nodes
**Operated on in parallel** - tasks executed on all chunks at the same time
