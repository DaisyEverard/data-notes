#### Unit Tests
Verifiy functionality of a single unit in isolation. Any calls outside of the one unit should be mocked out.

#### Integration Tests
Test how different components or systems work together, and that they function as a whole.
You can use pipeline expectations to validate table results and used a job with notebooks that test your data pipeline. You can also fetch data to a local or cloud workspace to run your tests externally once a job or pipeline runs.

#### System Tests / End-To-End Tests
Test the entire application with a real-world scenario. For example an end-to-end data pipeline in a job
